Entry for the make.fun bounty "The AI Agent Apology One-Liner": the program
writes one short apology line an AI agent sends its human right after an
accident, to `entry.txt` in the output directory.

Run with Node: `node main.ts` (writes to `$MAKEFUN_OUTPUT_DIR` or `/output`).
